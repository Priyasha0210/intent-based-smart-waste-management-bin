# Project Roadmap

## Implemented / demonstrated

1. Literature review and system architecture.
2. Real-time hand detection and landmark extraction.
3. Custom COME / NOT_COME gesture dataset collection.
4. LSTM gesture-classification experiment.
5. Random Forest gesture-classification experiment.
6. Real-time gesture detection prototype.

## Planned next stages

1. Increase training data and improve classification robustness.
2. Add confidence-based filtering and temporal smoothing.
3. Connect gesture output to the embedded controller.
4. Implement motor control and autonomous navigation.
5. Add voice/mobile-app control.
6. Add AI-based waste-type classification.
7. Implement automatic waste segregation.

The roadmap is based on the supplied research paper and project presentation.
