# Results

Documented results from the project presentation:

| Approach | Test accuracy | Notes |
|---|---:|---|
| LSTM | 67% | Showed substantial confusion between COME and NOT_COME on the 200-sample dataset. |
| Random Forest | 90% | Correctly classified all NOT_COME samples in the reported test set and gave more stable real-time predictions. |

The current repository contains the LSTM implementation source. The Random Forest implementation was reported and benchmarked in the project presentation, but its source file was not among the files supplied for this repository build.
